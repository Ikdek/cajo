Nova UI · Composants / Tailwind CSS

Les boutons.

Quatre dégradés, trois tailles et deux polices. Une même signature visuelle pour toutes vos actions.

Quatre couleurs, une identité

Les dégradés Nova UI, orientés à 135°. Le texte sombre conserve un contraste lisible sur les quatre palettes.

Violet Nebula

#8B5CF6 → #6366F1
--primary

Arctic Cyan

#06B6D4 → #0EA5E9
--secondary

Emerald Pulse

#10B981 → #059669
--success

Solar Amber

#F59E0B → #F97316
--warning

Voir le code HTML
<button type="button" class="ui-button ui-button--primary">Bouton</button>
<button type="button" class="ui-button ui-button--secondary">Bouton</button>
<button type="button" class="ui-button ui-button--success">Bouton</button>
<button type="button" class="ui-button ui-button--warning">Bouton</button>

La variante --warning correspond à Solar Amber. Les variantes sémantiques --danger et --neutral complètent les quatre palettes ci-dessus.

Les intentions complémentaires

Danger et neutre complètent les palettes Nova UI, conformément aux conventions du dépôt.

Voir le code HTML
<button type="button" class="ui-button ui-button--danger">Action destructive</button>
<button type="button" class="ui-button ui-button--neutral">Action neutre</button>

Une taille pour chaque contexte

Petit : 36 px · Moyen : 44 px · Grand : 52 px. La taille moyenne est utilisée par défaut. Privilégiez moyen ou grand sur les interfaces tactiles.

Voir le code HTML
<button type="button" class="ui-button ui-button--primary ui-button--sm">Petit bouton</button>
<button type="button" class="ui-button ui-button--primary ui-button--md">Bouton moyen</button>
<button type="button" class="ui-button ui-button--primary ui-button--lg">Grand bouton</button>

Deux expressions typographiques

Plus Jakarta Sans reprend la référence Nova UI. JetBrains Mono reprend la variante monospace prévue par les conventions partagées. Sans est la police par défaut.

Voir le code HTML
<button type="button" class="ui-button ui-button--primary ui-button--sans">Plus Jakarta Sans</button>
<button type="button" class="ui-button ui-button--primary ui-button--mono">JetBrains Mono</button>

Des états à essayer

Survolez un bouton, parcourez la page avec Tab ou maintenez le clic. Le dernier bouton utilise l’attribut natif disabled. Ces démonstrations ne déclenchent aucune action.

Voir le code HTML
<button type="button" class="ui-button ui-button--primary">Survolez-moi</button>
<button type="button" class="ui-button ui-button--secondary">Focus avec Tab</button>
<button type="button" class="ui-button ui-button--success">Maintenez le clic</button>
<button type="button" class="ui-button ui-button--primary" disabled>Indisponible</button>

Survol : 180 ms · Pression : 120 ms. Les transitions sont désactivées lorsque la réduction des animations est demandée.

Composez vos variantes

Associez une couleur, une taille et une police à la classe de base ui-button. Le HTML est commun aux versions Tailwind et Sass.

Voir le code HTML
<button type="button" class="ui-button ui-button--secondary ui-button--lg ui-button--mono">Continuer</button>
<button type="button" class="ui-button ui-button--success ui-button--sm ui-button--sans">Confirmer</button>
<button type="button" class="ui-button ui-button--warning ui-button--md ui-button--mono" disabled>En attente</button>

Utilisez type="button" pour une action et type="submit" pour soumettre un formulaire. Un lien de navigation reste un élément <a>.
